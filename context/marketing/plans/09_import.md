# 9. Import

**Status:** Planned.

**Theme:** Bring a deck you already have: paste a list or an Archidekt link, add to the deck or replace it, and see what didn't come in.

## Soundtrack

Quick and mechanical: tight drums, staccato strings, a ticking build, about 128 bpm.

## Script

Callum, the mix delivery (see README). Hook on screen: *Already have a Magic: The Gathering deck?*

| # | Line |
|---|---|
| 1 | [dramatically] Already have a Magic deck? |
| 2 | Paste the list. |
| 3 | Or drop an Archidekt link. |
| 4 | Add to your deck, or replace it. |
| 5 | [serious] It even tells you what didn't make it. |
| End card | Zwipe. The Magic: The Gathering deck builder. Free, no ads, on iOS, Android and web. |

## Pacing

| Time | On screen |
|---|---|
| 0-3s | Deck view, Import |
| 3-6s | A pasted text list |
| 6-9s | An Archidekt link instead |
| 9-12s | Add or Replace, then Import |
| 12-16s | The result: what came in and what didn't, then the full deck |
| 16-23s | End card, closing line |
