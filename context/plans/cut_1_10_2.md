## Why there is a 1.10.2 at all

The 2026-09-21 architecture work touches `zwiper`, so a client build is spent whether or not anything user-facing rides along. That makes it worth pairing with the small client fixes that are already specced rather than shipping a release nobody can see.

## Already done (internal, no changelog line)

Nothing here is user-visible; it belongs in the progress log, not the changelog.

- The `zerver` feature flag is gone: 598 gates to zero, and `zwiper` no longer depends on the server crate at all.
- Passwords are unprintable. `Password` and the new `Secret` redact `Debug` and `Display`; five auth request types and eight contract fields adopted `Secret`.
- API paths are constants, and the integration suite calls them, so a wrong path fails a test instead of shipping a 404.
- Every call is an `Endpoint`; client transport collapsed to one function.
