# iOS build history

Per-release iOS build numbers (`CFBundleVersion`). iOS and Android ship coupled
from the same `main`, so the fuller per-release detail (features, server halves,
migrations) lives in the Android
[`history.md`](../../../android/play-store/submission/history.md); this is the
iOS-side build-number log.

| 1.9.2 | 76 | The reliability + deck-list train. **Android `ndk-context` crash root-caused and fixed** after surviving five releases: `MainActivity` had no `launchMode`, so an explicit component start (notification, another app, the Play Store's Open button) created a second Activity in the live process and NativeActivity's native init ran twice; `launchMode="singleTask"` fixes it, and widening `configChanges` with `uiMode` fixes a second bug where a system theme change let the onDestroy process-kill silently close the app. Both are manifest patches now applied by `zcripts/android/patch_bundle.sh` (icons + back handler + manifest in one command). **Back-swipe overlay class fixed**: overlays only participate in back handling if they register with `OverlayBackStack`, so the shared `BottomSheet` now registers for every sheet, plus format_select, tag_select and printing_sheet.
