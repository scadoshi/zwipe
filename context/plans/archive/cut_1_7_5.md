## What this release carries

- Quick add search bar on deck cards (deck-aware, synergy off)
- Deck identity header (name + format/power/tag chips)
- Floating type-to-search results across all pickers (measured overlay on
  quick add)
- Quantity tap debounce (one net server call per burst)
- Undo on deck cards (adds, removals, coalesced qty bursts, board moves,
  printing swaps; per-deck in-memory stacks that survive navigation)
- PATCH migration client half: PATCH verb on all seven update endpoints,
  absolute-quantity deck-card body, clean Opdate wire form
- Changelog: twelve 1.7.5 bullets already in `zwipe-core` — What's New copy
  can lift from them
