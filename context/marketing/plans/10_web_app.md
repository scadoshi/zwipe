# 10. The web app

**Status:** Planned.

**Theme:** The same Zwipe in a browser at app.zwipe.net: wide windows, card details beside the card, the keyboard for swiping.

## Soundtrack

Modern and confident: orchestral hybrid with a steady pulse, bright brass, about 120 bpm.

## Script

Callum, the mix delivery (see README). Hook on screen: *The Magic: The Gathering deck builder, in your browser*

| # | Line |
|---|---|
| 1 | [dramatically] The Magic deck builder, in your browser. |
| 2 | Same decks. Same swipes. |
| 3 | Card details beside the card. |
| 4 | Arrow keys to swipe. |
| 5 | [shouts] Build anywhere! [serious] Pick up where you left off. |
| End card | Zwipe. The Magic: The Gathering deck builder. Free, no ads, on iOS, Android and web. |

## Pacing

| Time | On screen |
|---|---|
| 0-3s | app.zwipe.net opens on a wide window |
| 3-6s | Decks, then a deck page in two columns |
| 6-9s | Add with the details panel beside the card |
| 9-13s | Swiping with the arrow keys |
| 13-16s | The same deck on the phone |
| 16-23s | End card, closing line |
